Quick help

  • Capture: Ctrl+Shift+F. Screen Translate: Ctrl+Shift+T. If another app owns a shortcut, change it in Basic Settings; Screenshot Vault cannot override it.
  • Cannot find the window: use the tray icon to restore it. Closing the main window leaves the app in the tray; use tray Exit to stop it.
  • Missing screenshots: check the folder path in Basic Settings and the Gallery footer. Locate a missing folder or register another existing folder. Paused OCR affects searchable text, not file discovery. Do not delete your original files.
  • OCR trouble: check the selected language and engine. Tesseract includes English, Turkish, Japanese, Korean and Simplified Chinese. Windows OCR depends on installed Windows recognizers. Resume indexing for background text search; on-demand Screen Translate has its own OCR operation.
  • Translation trouble: choose EN→TR, TR→EN, KO→EN or EN→KO and check the language-pack/error status. Other directions are not included. Inference is local and loading the first model can take time; do not hide an error by treating it as a successful translation.
  • Windows startup: enable it with the Store app's permission flow. Windows user/policy disable can prevent startup. Enabling it opens the tray on sign-in, not a capture or foreground window.
  • Uninstall/data: original screenshots and the external Store profile are intended to remain. See the privacy policy for retained-state paths and safe manual removal. Do not delete the NSIS profile to troubleshoot a Store install.

Report a problem

Include your app version, Windows version, Store or NSIS installation channel, display scaling/monitor count when relevant, steps to reproduce, expected and actual results, and the visible error message. Use synthetic text/images if an example is needed. Review diagnostic logs before sending them; error redaction is not infallible. Do not send a full database, private screenshots, passwords, licensing secrets or account credentials.
