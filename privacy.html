What the application does with your information

Screenshot Vault captures screen content when you request a capture, including through a configured global shortcut. Screenshots can contain personal or sensitive information displayed by other applications. Check the selected area before saving or sharing it. The application does not continuously record your screen or automatically start capturing when Windows starts.

Screenshot files are saved to your configured screenshot folder. The default is the Screenshots subfolder of your actual Windows Pictures folder. You can register existing folders for browsing without moving their original files.

Gallery discovery reads supported image files in configured libraries. When OCR indexing is enabled, background workers recognize text and store searchable results and image information locally. OCR can therefore retain text that was visible in an image, including sensitive text. Pausing OCR stops indexing work; it does not erase results already stored or remove images from the Gallery. On-demand Screen Translate OCR is separate from background indexing.

Screen Translate processes the screen region you select and displays the crop, recognized text and translation until you replace or close the result. Its copy and save controls can put information on the clipboard or save it to disk. Screenshot capture can also copy images automatically if that preference is enabled. Windows clipboard history, clipboard synchronization and other apps with clipboard access are governed by your Windows settings and their behavior.

Offline processing and network activity

The included OCR and four translation directions run locally: English to Turkish, Turkish to English, Korean to English and English to Korean. The bundled Tesseract languages are English, Turkish, Japanese, Korean and Simplified Chinese. Windows OCR uses recognizers available on your system. These local operations do not require uploading screenshots or text, downloading translation models, or signing in to a Screenshot Vault account.

This release has no built-in cloud translation, advertising service or application-operated analytics upload service. Diagnostic information is written locally; it is not automatically sent to the publisher by the application. This describes the application's behavior, not a network isolation guarantee for a full-trust Windows desktop app.

Microsoft Store, Windows installation/updates, Windows language installation, system diagnostics, security software and any browser or support website may use network connections under their own policies. Your Pictures or library folders may be redirected to OneDrive or other synchronized/network locations. Saving a file there can cause synchronization outside Screenshot Vault. Local OCR/translation does not disable those services or make synced folders private.

Settings, local data and diagnostics

The application stores preferences, library registrations, a local database, OCR/search data, caches, diagnostic logs and a beta-agreement receipt in your Windows user profile. Logs include operation names, timestamps and error details. The application attempts to redact private paths/values from diagnostic errors; redaction is not a guarantee that every diagnostic file is free of personal information. Review anything before sharing it with support.

For the Microsoft Store package, the persistent profile is:

%LOCALAPPDATA%\ScreenshotVaultStore\TolgaGalipASLAN.ScreenshotVault_mppfp30vz0wht

The separate NSIS installation uses %LOCALAPPDATA%\ScreenshotVault unless explicitly configured otherwise. The Store app does not automatically import or overwrite that profile. Application data is not stored in your Pictures folder.

Startup and your controls

Store startup with Windows requires your permission and can be changed in the application or Windows Startup settings. Startup opens the tray app without taking screenshots. Closing the main window can leave the tray app running; choose Exit from the tray to stop the application. Global shortcuts operate while it runs and can be changed or disabled. You can choose screenshot folders, pause indexing and decide whether to use capture, translation, copy or save.

Retention and removal

Screenshots and registered external files remain in their original locations unless you explicitly use a file-changing action. Uninstalling the package is not intended to delete those images or the external persistent Store profile. The profile is designed to survive same-identity updates and reinstall; actual Windows retention behavior remains subject to installation testing, operating system behavior and user/administrator cleanup. This is not a backup service.

To remove retained Store settings, database, OCR results, caches and local logs, exit the application, back up anything you need, and remove only the Store profile directory above. This resets local application state; it does not remove your original screenshots or data held by Windows/cloud services. Do not delete the separate NSIS profile unless you intend to reset that installation too. Protect local data with appropriate Windows account, device and backup controls.
